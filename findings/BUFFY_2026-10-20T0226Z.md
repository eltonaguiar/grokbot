1. **Rebuild walk-forward `by_class`** (empty since 2026-04-15 — section 0). The
   single highest-priority item; without it no class has OOS evidence.

   approx is invalid). COMMODITY/ETF/FUTURES/MEME/PENNY have `bootstrap_ci=[None,None]`.
3. **Wilson (or Jeffreys) CIs on WR** for all n<20 slices (already hidden per
   display rule; CIs quantify how far from the 50% bar they actually are).
4. **White's Reality Check / SPA** where `spa_p=None` (COMMODITY/EQUITY/FOREX).
5. **PBO (Bailey-Lopez de Prado, CSCV)** where `pbo=None`.
6. **FDR / Benjamini-Hochberg** across the per-strategy search (we test many
   strategies; correct multiple comparisons).
7. **Block bootstrap for serial correlation** in trade returns (trades are not i.i.d.).
8. **COMMODITY paired-PnL test:** since only pf_ok fails at n=227, run a
   block-bootstrap PF CI + paired sign test on per-trade PnL to test whether
   PF>1.5 is statistically reachable. Most decisive single calculation for the
   leading candidate.
9. **Hurst / variance-ratio test** per class to assign mean-revert vs trend sleeves.
10. **HHI concentration** on symbol + source share (fix the `UNKNOWN`-source
    attribution, currently 87-99% share, before the single-source gate is trustworthy).
